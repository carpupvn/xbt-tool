🛠️ Công cụ Save — Tiệm Xôi Bà Tám

Giải mã · Chỉnh sửa · Ký lại · Tạo mã XBT cho app

⚠️ Sao lưu bản gốc trước khi sửa. Copy save gốc ra Notepad trước khi ghi đè.

1 Dán dữ liệu

Chấp nhận: save JSON {"f":2,"d":..}, mã XBT3 của app XBT3..., token g.xxx/r.xxx, link #xoi-transfer=…, hoặc JSON state thô.

📂
Kéo thả file save vào đây
hoặc · hoặc bôi đen text rồi thả vào đây · hoặc dán vào ô bên dưới

2 Chỉnh sửa state

Chưa có state
🎨 Bảng chỉnh sửa trực quan (tên tiếng Việt)
⚡ Ô chỉnh nhanh (day / money / chương...)
🧾 JSON thô (cho người rành kỹ thuật)

3 Ký lại & lấy save

Nút Ghi localStorage chỉ có tác dụng nếu tool mở cùng origin với game. Trên GitHub Pages, dùng Sao chép rồi dán vào Console / ô "Khôi phục dữ liệu" của game.

4 Tạo link chuyển dữ liệu

Link chứa fragment #xoi-transfer=… nên không gửi lên máy chủ.

5 Hướng dẫn nhanh

📖 Lấy save từ trình duyệt (web game)
  1. Mở game trên trình duyệt → F12 → tab Console.
  2. Chạy: copy(localStorage.getItem('xoi_bt_save')||localStorage.getItem('xoi_bt_save_bak'))
  3. Dán vào ô 1 của tool → Giải mã.
  4. Sửa → Ký lại (JSON) → Sao chép.
  5. Về Console game, chạy (thay PASTE):
(function(){var v=PASTE;localStorage.setItem('xoi_bt_save',v);localStorage.setItem('xoi_bt_save_bak',v);localStorage.setItem('xoi_fmt','2');location.reload();})()
📱 Lấy save từ app native (Android/iOS)
  1. Mở app Xôi Bà Tám → vào màn hình chính → bấm Sao lưu dữ liệu.
  2. Copy mã XBT3... mà app hiển thị.
  3. Dán vào ô 1 của tool → Giải mã.
  4. Sửa xong → Tạo mã XBT cho app → copy mã mới.
  5. Mở app → Khôi phục dữ liệu → dán mã XBT3 mới.
📂 Kéo thả file
  • Kéo file .json / .txt chứa save vào ô bước 1 → tự động giải mã.
  • Hoặc bôi đen save trong Notepad rồi kéo thả vào ô.
  • Click vào ô để mở hộp thoại chọn file.
🔐 Vì sao phải “Ký lại”?

Save có h là hash của d (hoặc s trong XBT). Sửa nội dung mà không tính lại h → game coi save hỏng. Tool copy nguyên hàm hash từ game nên luôn khớp.

❓ Lỗi thường gặp
  • “Chữ ký không khớp” — bấm Ký lại để tạo save mới.
  • “Mã XBT sai checksum” — mã bị cụt khi copy, kiểm tra đã copy đủ ký tự chưa.
  • Ghi localStorage xong game không đổi — kiểm tra IndexedDB xoi_bt và xoi_fmt='2'.
  • App báo “Số tiền không khớp sổ thu chi” — game audit money == sum(ledger.net). Sửa ledger tương ứng.
Tool tĩnh — không gửi dữ liệu đi đâu cả.
